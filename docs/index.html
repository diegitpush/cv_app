Data Engineer & Software Developer

Allianz Direct (November 2023 - today)

Data Engineer and software developer in charge of building, maintaining and scaling a unified Data Platform as a core component of a data-centric company. This data platform is a self-service data lakehouse, in which different domain users can autonomously generate new data pipelines by filling templates, which are automatically deployed on Databricks, and which custom logic is developed in Scala and Python. Our goal is a data platform in which employees all across the company can include data as a core component of their workflows and decision processes, making this as agile and easy for them as possible, while still following software and governance best practices.

My responsabilities include:
Develop an ecosystem (custom libraries, CI/CD pipelines, IaC) in which users can automatically ingest data (Kafka, APIs, files) and transform it (Python, dbt) by just filling templates
Build custom pipelines for data analytics and machine learning use cases
Data governance (IAM, GDPR, data quality)
Platform security (access controls, security by depth)
Cost optimization (storage and compute)
Platform monitoring (both internal and user-facing dashboards)

Tech stack: Data Platform based on Azure Databricks. Code developed in Scala, Python and SQL. GitHub used for version control and CI/CD. Terraform for IaC. For ingestion and transformation: Kafka, Spark, pandas, dbt.
